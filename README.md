# 📄 ProPDF — Повнофункціональний Онлайн Редактор PDF

*(Працює безпосередньо у браузері на комп'ютерах, смартфонах та планшетах без встановлення стороннього ПЗ)*

---

## 🚀 Як запустити локально

### 1. Веб-версія (швидкий запуск у браузері)
```bash
npm run dev
```
Відкрийте у браузері [http://localhost:5173](http://localhost:5173).

### 2. Нативний десктопний додаток для macOS (Electron)
```bash
npm run electron
```

### 3. Збірка для продакшену
```bash
npm run build
```

## 🌟 Ключові можливості

### 1. Редагування та форматування тексту
- **Пряме інлайн-редагування**: клікніть на будь-який рядок тексту в документі у режимі «Редагувати вміст» — і редагуйте його прямо на місці!
- **Додавання тексту**: вільне розміщення нових текстових блоків у будь-якій точці сторінки.
- **Повна панель форматування**:
  - Шрифти: Sans-Serif, Roboto, Inter, Serif, Monospace.
  - Розмір шрифту (pt) від 6 до 96 з кнопками покрокового збільшення/зменшення.
  - Накреслення: **Жирний (Bold)**, *Курсив (Italic)*, <u>Підкреслений</u>, Закреслений.
  - Вирівнювання: по лівому краю, по центру, по правому краю.
  - Колір тексту та колір фону/виділення.
  - Повна підтримка української мови (кирилиці UTF-8: `і`, `ї`, `є`, `ґ`).

### 2. Робота із зображеннями
- **Вставка з буфера обміну (`Cmd+V`)**: зробіть знімок екрана (`Cmd+Shift+4`) або скопіюйте картинку — і натисніть `Cmd+V`, щоб миттєво вставити її на поточну сторінку!
- **Вставка з файлу**: підтримка PNG, JPEG, SVG, WebP.
- **Трансформація**: 8 кутових маркерів зміни розміру, вільне перетягування мишею.
- **Поворот на 90°**, дзеркальне відображення по горизонталі/вертикалі (Flip X / Flip Y).
- **Налаштування прозорості (opacity)** від 0% до 100%.
- **Керування шарами**: порядок відображення, видалення.

### 3. Професійні інструменти (PRO Tools)
- **Електронний підпис (Signature)**:
  - Малювання підпису мишею/тачпадом із згладжуванням ліній.
  - Генерація каліграфічного підпису за введеним іменем.
  - Завантаження фото/скану підпису з прозорим фоном.
- **Штампи (Stamps)**:
  - Встановлені українські та міжнародні штампи: «ЗАТВЕРДЖЕНО», «КОПІЯ ВІРНА», «ОПЛАЧЕНО», «КОНФІДЕНЦІЙНО», «ПЕРЕВІРЕНО», «APPROVED», «DRAFT».
  - Автоматичне додавання поточної дати.
  - Конструктор власного штампа.
- **Малювання та анотації**:
  - Олівець / Ручка (Freehand Pen) з вибором кольорів та товщини.
  - Маркер-хайлайтер (Highlighter) із напівпрозорою лінією.
  - Геометричні фігури: прямокутник, коло/овал, стрілка, лінія.
- **Коректор (Whiteout / Redaction)**:
  - Миттєве забілювання небажаних ділянок або приховування конфіденційних даних.
- **Об'єднання PDF (Merge PDF)**:
  - Приєднання сторінок з інших PDF документів.

### 4. Організатор сторінок (Page Organizer)
- Перегляд мініатюр усіх сторінок у бічній панелі.
- Зміна порядку сторінок (Move Up / Move Down).
- Поворот сторінки на 90° за годинниковою стрілкою.
- Дублювання сторінки.
- Видалення сторінки.
- Додавання нової чистої сторінки формату A4.

### 5. Інтерфейс та навігація
- **Автоматична тема**: синхронізація зі світлою/темною темою macOS + кнопка ручного перемикання.
- **Масштабування**: Zoom In/Out, Fit Width, 100%, плавне колесо миші.
- **Історія змін**: повний стек `Undo / Redo` (`Cmd+Z`, `Cmd+Shift+Z`).
- **Збереження та експорт**: генерація валідного компактного PDF документу з усіма правками.
- **Прямий друк**: відправка на принтер прямо з редактора (`Cmd+P`).

## ⌨️ Гарячі клавіші (Shortcuts)

| Комбінація | Дія |
|---|---|
| `⌘ + Z` | Скасувати дію (Undo) |
| `⌘ + ⇧ + Z` / `⌘ + Y` | Повторити дію (Redo) |
| `⌘ + S` | Зберегти / Експортувати PDF |
| `⌘ + P` | Друк документа |
| `⌘ + V` | Вставити картинку з буфера обміну |
| `⌘ + +` / `⌘ + -` | Збільшити / зменшити масштаб |
| `⌘ + 0` | Скинути масштаб на 100% |
| `V` | Інструмент «Вибір» |
| `E` | Інструмент «Редагувати вміст» |
| `T` | Додати текст |
| `I` | Додати зображення з файлу |
| `P` | Олівець (вільне малювання) |
| `H` | Маркер-хайлайтер |
| `W` | Коректор (Whiteout) |
| `S` | Додати підпис |
| `Delete` / `Backspace` | Видалити виділений елемент |
| `Esc` | Скинути виділення / вийти з режиму |
